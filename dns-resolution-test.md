Practical Lab 3: DNS Resolution Testing

1. Objective

Test whether Windows can resolve domain names using the nslookup command and compare the results with a ping test.

2. Environment

- Operating system: Windows 10
- Tool: Windows Command Prompt
- Commands: nslookup and ping

3. Tests Performed

Test 1: Microsoft DNS Lookup

Command: "nslookup microsoft.com"

Result: Successful.

Interpretation: The domain name resolved successfully during testing.

Test 2: Google DNS Lookup

Command: "nslookup google.com"

Result: Successful.

Interpretation: The domain name resolved successfully during testing.

Test 3: Microsoft Connectivity Test

Command: "ping microsoft.com"

Result: Successful.

Interpretation: The domain resolved, and the destination responded to the ping test.

4. Overall Findings

Both DNS lookups succeeded, and the ping test to Microsoft was successful.

The results indicate that DNS resolution and connectivity to the tested destination were working at the time of testing.

5. Troubleshooting Actions

No configuration changes were necessary because all tests succeeded.

6. Skills Practised

- DNS resolution testing
- Windows Command Prompt
- nslookup
- Ping testing
- Basic network troubleshooting
- Technical documentation

7. Next Steps

Investigate how DNS failures appear, learn to distinguish DNS issues from connectivity problems, and practise documenting troubleshooting results.
