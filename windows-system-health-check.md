Practical Lab 4: Windows System Health Check

1. Objective

Inspect the Windows operating system version, available storage, installed applications and Windows Update status.

2. Environment

- Operating system: Windows 10
- Version: 1903
- OS build: 18362.207
- Total storage: 465 GB
- Available storage: 151 GB

3. Installed Applications

Applications identified during the inspection:

- Google Chrome
- Avast Free Antivirus
- Gmail

4. Storage Assessment

The computer has 465 GB of total storage, with 151 GB available.

Approximately 32% of the storage capacity is free. Based on these figures, low storage is not an immediate concern.

5. Windows Update Assessment

The Windows Update screen indicated that updates were available.

The operating system version and build are outdated. Further investigation is required to determine the available updates and the computer's upgrade eligibility.

6. Initial Findings

- The Windows installation is outdated.
- Available storage appears sufficient based on the recorded figures.
- Installed applications were identified.
- Windows Update requires further investigation.

7. Actions Taken

The operating system version, storage capacity, available space, installed applications and update status were inspected.

No operating system upgrade or other system changes have been performed as part of this investigation.

8. Skills Practised

- Windows System Information
- Operating system version identification
- Storage assessment
- Installed application inspection
- Windows Update status inspection
- Technical documentation

9. Next Steps

Confirm the processor and system architecture, inspect the Windows Update message, and assess compatibility with a supported operating system.
