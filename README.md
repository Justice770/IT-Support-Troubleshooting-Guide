Troubleshooting Guides

1. Computer Running Slowly

Possible causes:

- Too many applications running.
- Insufficient available storage.
- Applications using excessive system resources.

Troubleshooting steps:

1. Restart the computer.
2. Close unnecessary applications.
3. Check available storage space.
4. Use Task Manager to identify applications using excessive CPU or memory.
5. Install available updates where appropriate.
6. Restart and check whether performance improves.

2. Internet Connection Not Working

Possible causes:

- Wi-Fi is disabled.
- Router or network connection problems.
- Incorrect network settings.

Troubleshooting steps:

1. Check whether Wi-Fi is enabled.
2. Confirm that the device is connected to the correct network.
3. Check whether other devices can connect.
4. Restart the router only if authorised and appropriate.
5. Disconnect and reconnect to the network.
6. If the problem continues, record the error and escalate it to the network administrator.

3. Application Not Opening

Possible causes:

- Temporary application error.
- Outdated software.
- Corrupted application files.

Troubleshooting steps:

1. Close and reopen the application.
2. Restart the computer.
3. Check for available application updates.
4. Record any error messages.
5. If necessary, request assistance before repairing or reinstalling the application.

4. Printer Not Printing

Possible causes:

- Printer is offline.
- Paper or ink is unavailable.
- Connection problems.
- Print jobs are stuck in the queue.

Troubleshooting steps:

1. Check that the printer is powered on.
2. Check paper and ink or toner levels.
3. Confirm that the printer is connected to the correct computer or network.
4. Check the printer queue for stuck jobs.
5. Print a test page if appropriate.
6. Record any error messages and escalate unresolved issues.

Basic IT Support Best Practices

- Identify the problem before making changes.
- Ask the user relevant questions.
- Follow troubleshooting steps in a logical order.
- Protect user data and privacy.
- Document actions taken and results.
- Escalate problems that are outside your knowledge or permissions.
